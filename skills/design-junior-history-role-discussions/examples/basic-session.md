# 完整示例：商鞅变法角色讨论

## 用户输入

```text
八年级，40 分钟，主题是商鞅变法。目标是理解改革为何得到不同群体的支持或反对，并用教材证据评价改革对秦国富强的作用。班级 44 人，使用统编教材相关内容，不要补写教材没有的史料。
```

## 预期方案摘要

### 课堂概览

- 中心问题：商鞅变法为何会让不同群体形成不同立场，它对秦国富强的作用应如何评价？
- 可检查目标：学生能引用至少两条教材证据解释立场差异，并区分措施、直接影响和长期结果。

### 角色/视角

1. 改革执行者：关注法令落实与国家治理。
2. 旧贵族：关注世袭特权变化。
3. 农户：关注土地、生产和赋役影响。
4. 军功受益者：关注军功授爵带来的机会。

角色卡不编写人物台词，只列历史处境、可用证据、必答问题和禁止越界。

### 讨论流程

- 4 分钟：导入中心问题。
- 5 分钟：个人读证并标记“措施/影响/评价”。
- 7 分钟：角色组形成“主张 + 两条证据 + 一个限制”。
- 8 分钟：各组陈述。
- 8 分钟：交叉质询，要求指出证据边界。
- 5 分钟：退出角色，个人重写结论。
- 3 分钟：教师收束与退出票。

### 预判误区

- 表现：把改革措施直接等同于秦统一六国的唯一原因。
- 最小纠正：补画“措施 → 近期影响 → 国力变化 → 多因素结果”链条。
- 再验证：哪一条证据只能说明近期影响，不能单独证明长期结果？

### 退出票

用 3-5 句写出个人结论、最有力证据和一个仍需保留或核对的问题。
