# 来源分析

## 已验证事实

- 研究来源：`THU-MAIC/OpenMAIC`。
- GitHub 地址：https://github.com/THU-MAIC/OpenMAIC
- 截至 2026-07-22 查询：19,934 Stars、3,911 Forks，最近更新时间为 2026-07-22。
- 许可证：MIT。
- 原项目定位：把主题或文档转成多智能体互动课堂，包含讲授、讨论、测验、模拟和项目式学习。
- 近期公开需求包括分支课堂、费曼模式、测验答案泄露防护、运行记录和编辑能力。

## 原能力结构

- 输入：主题或材料。
- 流程：生成课程内容，安排教师与同伴代理互动，加入测验或活动。
- 输出：可播放、可编辑或可导出的互动课堂。
- 用户价值：降低构建互动课程的技术和时间成本。

## 转换机会

通用多智能体课堂依赖模型、前端、存储和媒体服务，教师也需要自行判断角色是否符合课程标准、史料是否真实、活动能否在真实课时内完成。教育 Skill 因此不复刻平台，而是提炼“多视角互动 + 分阶段课堂 + 形成性评价”方法，转换为初中历史教师可检查、无外部依赖的课堂讨论设计流程。
