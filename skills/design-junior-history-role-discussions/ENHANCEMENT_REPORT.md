# 实质提升报告

| 原能力在本场景的不足 | 本 Skill 的提升 | 为什么有效 | 验证方式 |
|---|---|---|---|
| 通用课程范围过宽 | 收窄到七至九年级历史讨论课 | 输入和验收更明确 | 检查年级、课时、目标和产物是否齐全 |
| 多角色容易变成表演 | 使用证据约束的利益相关方/分析视角 | 讨论回到历史解释而非戏剧化台词 | 检查每个角色能否回指证据编号 |
| 模型可能编造史料 | 设置四类证据标记和待核对机制 | 降低虚假引语与数字进入课堂的风险 | 无出处材料必须标记待核对 |
| 生成流程难落到真实课堂 | 为每轮提供时间、产物、停止条件和压缩方案 | 教师可在 20-45 分钟内实施 | 累计时间不得超过课时 |
| 只看最终立场 | 增加证据使用、解释质量和回应异议量规 | 评价学习过程而非立场一致性 | 四维量规均有 0-2 分可观察描述 |
| 缺少学习闭环 | 加入退出票和下一阶段条件 | 教师能判断补练还是升级 | 退出票必须含结论、证据和保留 |
| 创伤历史角色扮演有风险 | 明确改用史料分析和伦理讨论 | 降低对未成年人的情绪伤害和污名化 | 安全测试检查拒绝沉浸式受害者/施害者扮演 |
