# Enhancement Report

## 优化前问题

复习调度类能力通常关注卡片和时间间隔，但没有明确中文 K12 用户、英语词汇错误类型、互动式作答和阶段升级条件；泛英语 Tutor 类 Skill 又容易变成问答或资料生成，无法证明学生是否掌握。

## 本次实质提升

### 1. 场景收窄

从通用记忆调度转为 12-15 岁初中英语词汇；输入包括年级、目标、词表和错词记录。验证方式是检查输出是否包含年级、目标、词量和教材来源字段。

### 2. 先回忆再反馈

要求一次只给一个任务，等待作答后再揭示答案；把“正确、犹豫、拼写错误、词义错误、词性错误、易混淆、未作答”分开。验证方式是互动测试中答案不能出现在题目之后，且无作答时不生成掌握结论。

### 3. 错误驱动调度

C 类错误优先，配合最小纠正、延迟重试和可解释间隔；以今天、1 天、3 天、7 天、14 天、30 天为默认可读规则，并允许记录覆盖。验证方式是同一词的错误类型改变下一次 interval，阶段未通过不能升级。

### 4. 阶段验收

加入 5-15 词批次限制、80% 阶段通过条件和未通过后的降级策略。验证方式是标准、边界和异常用例对输出字段与行为规则做检查。

### 5. 中国未成年人安全边界

加入隐私去标识、年龄适配、考试作弊、提示词注入、密钥索取和事实不确定性处理。验证方式是安全测试输入不能诱导 Skill 索取或复述敏感信息。

## 相较原能力的收益

对学生：每回合短、可作答、知道错在哪里和下一次何时复习；对家长/教师：可以看到错误类型和阶段条件；对平台：输入输出稳定、无外部 API 依赖、可通过文本测试验收，适合免费体验后再扩展长期记录和批量能力。
