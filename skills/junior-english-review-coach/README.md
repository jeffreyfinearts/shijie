# 初中英语单词复习教练

面向 12-15 岁初中生的短回合英语词汇训练 Skill。核心不是一次性输出资料，而是把词表转成“主动回忆 → 错误诊断 → 间隔复习 → 阶段测试”的闭环。

## 适用

- 七至九年级英语词汇复习
- 小测前的 10-15 分钟短训练
- 家长/教师根据错词记录安排下一次复习

## 快速使用

提供年级、目标、5-15 个单词和已知错题记录。例如：

> 八年级，周五小测。请先测我这 6 个词，不要直接给答案；上次 achieve 和 afford 拼写错。

## 设计原则

- 先回忆后揭示答案；
- 没有学生作答就不推断掌握；
- 优先处理易错词，再用混合小测验证；
- 复习间隔可解释、可调整，不承诺学习结果；
- 不收集未成年人身份信息，不需要 API Key。

## 文件

- `SKILL.md`：运行规范；
- `references/output_schema.md`：输出字段约定；
- `examples/basic_session.md`：完整示例；
- `tests/cases.json`：标准、边界、错误、年龄和安全测试。
